## কীভাবে কাজ চলবে

1. প্রথমে `07_DECISIONS.md` পড়ে প্রতিটি সিদ্ধান্তে ✅ দিন বা বদলান। ডিফল্টগুলো যুক্তিসহ দেওয়া আছে; না বদলালে ডিফল্টই চলবে।
2. `PROMPTS.md` থেকে **P00**-এর প্রম্পট কপি করে Claude Code-এ দিন।
3. Claude Code আগে পরিকল্পনা দেখাবে → আপনি অনুমোদন দেবেন → কোড → টেস্ট → ফেজের "শেষ হওয়ার শর্ত" রিপোর্ট।
4. সব শর্ত পূরণ হলে কমিট, তারপর পরের ফেজ। একটা ফেজ শেষ না হলে পরেরটা শুরু হবে না।

## "০% ভুল" কীভাবে নিশ্চিত হবে

কোনো সফটওয়্যারে "কখনো বাগ হবে না" প্রতিশ্রুতি দেওয়া যায় না। এখানে লক্ষ্য হলো **টাকা ও স্টকের ভুল ধরা না পড়ে থাকতে না পারা**:

- প্রতিটি পোস্টিং একটি কেন্দ্রীয় ইঞ্জিন দিয়ে যায় এবং commit-এর আগে নিজেই মিলিয়ে দেখে (ইনভেরিয়েন্ট)।
- প্রতিদিন রিকনসিলিয়েশন চলে: GL ইনভেন্টরি = স্টক মূল্য, AR = কাস্টমার বাকি, ক্যাশ রিপোর্ট = ক্যাশ অ্যাকাউন্ট। অমিল হলে ড্যাশবোর্ডে লাল সতর্কতা।
- প্রতিটি ফেজে আগে ব্যর্থ টেস্ট, তারপর কোড। রিপোর্টের প্রতিটি সংখ্যা জার্নাল থেকে আসে, তাই দুই রিপোর্টে একই সংখ্যা দুই রকম হতে পারে না।
