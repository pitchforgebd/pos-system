# Claude Code প্রম্পট

প্রতি ফেজে নিচের প্রম্পট হুবহু কপি করে দিন। `PXX` আর ফাইলের নাম বদলাবেন শুধু। একটা ফেজ শেষ (DoD সব ✔ ও কমিট) না হলে পরেরটা দেবেন না।

## প্রতিটি ফেজের মূল প্রম্পট

```
docs/v2/00_GROUND_RULES.md পড়ো এবং পুরো কাজে মেনে চলো।
তারপর docs/v2/01_ARCHITECTURE.md থেকে 07_DECISIONS.md পর্যন্ত পড়ো,
এবং docs/v2/phases/PXX_<নাম>.md ফাইলটি ভালোভাবে পড়ো।

এখন শুধু পরিকল্পনা দাও, কোড লিখবে না:
১. এই ফেজের প্রতিটি টাস্ক কোন কোন ফাইল বদলাবে
২. কোন migration লাগবে
৩. কোন টেস্ট আগে লিখবে (ব্যর্থ টেস্ট)
৪. 07_DECISIONS.md-এ এই ফেজের কোনো সিদ্ধান্ত ফাঁকা থাকলে প্রশ্ন

আমার অনুমোদনের পর টাস্ক ১ থেকে একটা একটা করে শুরু করবে।
প্রতিটি টাস্ক শেষে typecheck, lint, সংশ্লিষ্ট টেস্টের ফল দেখাবে।
উত্তর বাংলায় দেবে।
```

## অনুমোদনের পর

```
পরিকল্পনা ঠিক আছে। টাস্ক ১ শুরু করো। শেষ হলে ফল দেখিয়ে থামো।
```

## পরের টাস্কে

```
ঠিক আছে, পরের টাস্ক।
```

## ফেজ শেষে

```
এই ফেজের DoD চেকলিস্টের প্রতিটি লাইনে ✔ বা ✘ দাও, প্রমাণসহ (কমান্ড আউটপুট)।
docs/v2/08_AUDIT_TRACEABILITY.md-এ এই ফেজে বন্ধ হওয়া আইটেমে ✔ দাও।
সব ✔ হলে কমিট করো: v2(PXX): <সংক্ষেপ>
```

## কোনো বাগ বা অমিল পেলে

```
এই সমস্যাটা দেখো: <কী দেখলাম, কোন পেজ, কোন সংখ্যা>
আগে কারণ খুঁজে বের করো এবং একটা ব্যর্থ টেস্ট লেখো যেটা সমস্যাটা ধরে।
টেস্ট ব্যর্থ হতে দেখিয়ে তারপর ফিক্স করো। assertBooksReconcile সবুজ কিনা দেখাও।
```
