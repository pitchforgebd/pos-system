# রিপোর্ট স্পেসিফিকেশন

সব রিপোর্টের সাধারণ নিয়ম:

- উৎস: শুধু পোস্টেড `journal_lines`, `stock_ledgers` ও ডকুমেন্ট হেডার। খসড়া/বাতিল বাদ।
- তারিখ: `businessDate` (Asia/Dhaka)। "দৈনিক" = একটি দিন; সব রিপোর্টে তারিখ-সীমাও চলবে।
- ফিল্টার: ব্রাঞ্চ (ব্যবহারকারীর অনুমতির মধ্যে, "সব ব্রাঞ্চ" অনুমতি থাকলে), আর রিপোর্ট-নির্দিষ্ট ফিল্টার।
- প্রতিটি রিপোর্টের নিচে **মিলের লাইন**: সূত্রটি মিলছে কিনা সবুজ ✔ / লাল ✘ (নিচে "পরিচয়" দেখুন)। লাল হলে সংখ্যাটি এবং পার্থক্য দেখাবে।
- আউটপুট: স্ক্রিন, প্রিন্ট (A4), CSV, Excel (.xlsx)।
- পারমিশন: `reports.view`, এক্সপোর্টে `reports.export`; লাভ-ক্ষতি ও cost দেখাতে `reports.profit`।

---

## দৈনিক ১০টি রিপোর্ট

### ১. দৈনিক Sales Report

| কলাম | সূত্র |
| --- | --- |
| ইনভয়েস নং, সময়, কাস্টমার, জেলা, চ্যানেল, প্রাইস লেভেল | হেডার |
| মোট (gross), ডিসকাউন্ট, VAT, চার্জ, নিট মোট | sale লাইন |
| নগদে পাওয়া (একই দিনের রসিদ), বাকি | allocation |
| পেমেন্ট স্ট্যাটাস | allocation |
| COGS ও লাভ (পারমিশনসাপেক্ষ) | sale_items.unitCost |

সারাংশ: ইনভয়েস সংখ্যা, মোট বিক্রি, রিটার্ন, নিট বিক্রি, পেমেন্ট মেথড অনুযায়ী, পণ্য/ক্যাটাগরি অনুযায়ী শীর্ষ ১০।
**পরিচয়:** নিট বিক্রি − VAT − চার্জ = জার্নালে SALES (4100) ক্রেডিট − ডেবিট সেই দিনের।

### ২. দৈনিক Stock Report

প্রতি পণ্য (ব্রাঞ্চ/গুদাম): শুরুর পরিমাণ, ক্রয়, রিটার্ন-ইন, ট্রান্সফার-ইন, অন্যান্য ইন, বিক্রি, সাপ্লায়ার রিটার্ন, ট্রান্সফার-আউট, ড্যামেজ/মেয়াদ, Take-off, অ্যাডজাস্টমেন্ট, শেষ পরিমাণ, avg cost, মূল্য, স্ট্যাটাস (LOW/OUT)।
**পরিচয়:** শুরু + ইন − আউট = শেষ (প্রতি সারি); Σ শেষ মূল্য = GL 1400 ব্যালান্স সেই দিন শেষে।

### ৩. দৈনিক Due Taka Report (বাকি)

দুই অংশ — কাস্টমার ও Vendor। প্রতি পার্টি: শুরুর বাকি, নতুন বাকি (ইনভয়েস/বিল), আদায়/পরিশোধ, রিটার্ন সমন্বয়, অগ্রিম সমন্বয়, শেষ বাকি, সবচেয়ে পুরনো অপরিশোধিত ইনভয়েসের তারিখ, ওভারডিউ।
**পরিচয়:** Σ কাস্টমার শেষ বাকি = AR (1300) ব্যালান্স; Σ Vendor = AP (2100)।

### ৪. দৈনিক Condition Taka Report

প্রতি কুরিয়ার: শুরুর পাওনা, নতুন COD হস্তান্তর, ডেলিভারি চার্জ, Condition চার্জ, ফেরত পার্সেল, সেটেলমেন্টে পাওয়া, শেষ পাওনা। নিচে শিপমেন্ট-ভিত্তিক তালিকা (স্ট্যাটাস, COD, চার্জ, দিন পার)।
**পরিচয়:** Σ শেষ পাওনা = COURIER_AR (1350) ব্যালান্স।

### ৫. দৈনিক Payment Taka Report (টাকা বাইরে গেছে)

প্রতিটি বহির্গামী লেনদেন: Vendor পেমেন্ট, খরচ, রিফান্ড, Vendor অগ্রিম, ঋণ পরিশোধ, মালিকের উত্তোলন, সম্পদ ক্রয়, ব্যাংক/মোবাইল চার্জ, contra আউট। কলাম: সময়, ধরন, নম্বর, পার্টি/খাত, কোন অ্যাকাউন্ট থেকে, পরিমাণ, চার্জ, কে।
সারাংশ: ধরন অনুযায়ী ও অ্যাকাউন্ট অনুযায়ী।
**পরিচয়:** মোট = সব MONEY অ্যাকাউন্টে সেই দিনের ক্রেডিট (contra আলাদা দেখিয়ে)।

### ৬. দৈনিক Receive Taka Report (টাকা এসেছে)

রসিদ (বিক্রির সময় ও পরে), কাস্টমার অগ্রিম, কুরিয়ার সেটেলমেন্ট, অন্যান্য আয়, মূলধন, ঋণ গ্রহণ, contra ইন। একই কলাম কাঠামো।
**পরিচয়:** মোট = সব MONEY অ্যাকাউন্টে সেই দিনের ডেবিট।

### ৭. দৈনিক লাভ-ক্ষতি Report

```
নিট বিক্রি (4100)
+ চার্জ আয় (4200)
− বিক্রিত পণ্যের ব্যয় (5100)
= মোট লাভ (Gross Profit)
− স্টক ক্ষতি/লাভ (5200, 4300)
− খরচ (6000 গ্রুপ; খাত অনুযায়ী লাইন: পরিবহন, Condition চার্জ, ব্যাংক চার্জ, মোবাইল চার্জ, বেতন ...)
+ অন্যান্য আয় (4400)
− PPV (5300)
= নিট লাভ/ক্ষতি
```

মাসিক খরচের দৈনিক ভাগ ঐচ্ছিক সেটিং (ডিফল্ট বন্ধ — খরচ যেদিন পোস্ট সেদিন)।
**পরিচয়:** নিট = সব আয়-ব্যয় অ্যাকাউন্টের নিট (ট্রায়াল ব্যালান্স থেকে)।

### ৮. দৈনিক খরচের Report

খাত অনুযায়ী (মাসিক স্থির / পরিবর্তনশীল / বিবিধ), প্রতিটি খরচ ভাউচার, কোন অ্যাকাউন্ট থেকে, `periodMonth`, চার্জসহ। মাসিক ভিউতে বাজেট বনাম আসল।
**পরিচয়:** মোট = 6000 গ্রুপে সেই দিনের নিট ডেবিট।

### ৯. দৈনিক Bank Balance Report

প্রতি ব্যাংক ও মোবাইল অ্যাকাউন্ট: শুরুর ব্যালান্স, জমা, উত্তোলন, চার্জ, শেষ ব্যালান্স; লেনদেন তালিকা।
**পরিচয়:** শুরু + ডেবিট − ক্রেডিট = শেষ = GL ব্যালান্স।

### ১০. দৈনিক Cash Balance Report

প্রতি ব্রাঞ্চ ও শিফট: শুরুর ক্যাশ, বিক্রির ক্যাশ, আদায়, অগ্রিম, অন্যান্য ইন, খরচ, পেমেন্ট, রিফান্ড, ব্যাংকে জমা (contra), শেষ ক্যাশ; শিফট গণনা (expected/actual/পার্থক্য)।
**পরিচয়:** শেষ = GL 1100 ব্যালান্স; Σ শিফট expected = সেই শিফটগুলোর CASH লাইন।

| রিপোর্ট | বিষয়বস্তু |
| --- | --- |
| মাসিক লাভ-ক্ষতি | উপরের ৭-এর কাঠামো, মাস অনুযায়ী কলাম (১২ মাস পাশাপাশি), গত বছরের সাথে তুলনা |
| জেলা × মাস | বিক্রি, কাস্টমার সংখ্যা, বাকি, গড় অর্ডার মূল্য — জেলা সারি, মাস কলাম; মানচিত্র ঐচ্ছিক |
| অর্ডার রেফারেন্স | অর্ডার/ইনভয়েস/শিপমেন্ট/বাইরের রেফ দিয়ে খুঁজুন → পুরো টাইমলাইন |
| পেমেন্ট স্ট্যাটাস | ইনভয়েস ও বিল — UNPAID/PARTIAL/PAID, বয়স, ওভারডিউ |
| কাস্টমার প্রোফাইল | তথ্য, মোট কেনা, শেষ কেনা, বাকি, অগ্রিম, লেজার, ইনভয়েস, রিটার্ন, SMS ইতিহাস |
| Vendor প্রোফাইল | তথ্য, মোট ক্রয়, বাকি, অগ্রিম, লেজার, বিল, রিটার্ন |
| পণ্যভিত্তিক বিক্রি ও মার্জিন | পণ্য/ক্যাটাগরি/ব্র্যান্ড, পরিমাণ, বিক্রি, COGS, মার্জিন % |
| স্টক ভ্যালুয়েশন | যেকোনো তারিখে, avg cost-এ |
| মেয়াদ ও লট | লট, মেয়াদ, বাকি দিন, পরিমাণ, মূল্য |
| Take-off ও ড্যামেজ | উদ্দেশ্য/কারণ অনুযায়ী পরিমাণ ও মূল্য |
| VAT | মাসিক আউটপুট, ইনপুট, নিট প্রদেয় |
| সম্পদ রেজিস্টার | স্থায়ী সম্পদ, অবচয়, বর্তমান মূল্য |
| ট্রায়াল ব্যালান্স, ব্যালান্স শিট, ক্যাশ ফ্লো, অ্যাকাউন্ট স্টেটমেন্ট, ডে-বুক | মানক হিসাবের রিপোর্ট |
| রিকনসিলিয়েশন | সব পরিচয় এক পাতায়: ✔/✘, পার্থক্য, কবে থেকে |

## ড্যাশবোর্ড (আজকের দিন, ঢাকা)

কার্ড: আজকের বিক্রি, নগদ আদায়, নতুন বাকি, বাকি আদায়, খরচ, আজকের লাভ, ক্যাশ ব্যালান্স, ব্যাংক+মোবাইল ব্যালান্স, কুরিয়ারে আটকে থাকা টাকা, মোট কাস্টমার বাকি, মোট Vendor বাকি, LOW/OUT স্টক, পেন্ডিং অর্ডার (স্ট্যাটাস অনুযায়ী), মেয়াদ শেষ হবে। প্রতিটি কার্ড উপরের রিপোর্টের একই query থেকে (লাইভ অডিটের LV-1-এর মতো অমিল অসম্ভব)।
