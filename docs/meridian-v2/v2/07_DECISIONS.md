# সিদ্ধান্ত তালিকা

প্রতিটিতে প্রস্তাবিত ডিফল্ট দেওয়া আছে। আপনি "সিদ্ধান্ত" ঘরে ✅ (ডিফল্ট মানলাম) অথবা নিজের উত্তর লিখুন। যে ফেজে লাগবে তার আগে অবশ্যই পূরণ হতে হবে; Claude Code পূরণ না হওয়া সিদ্ধান্তে থেমে জিজ্ঞেস করবে।
