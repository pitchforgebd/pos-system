# P04 — পণ্য, দাম ও বারকোড

**লক্ষ্য:** পণ্য সম্পূর্ণ ব্যবস্থাপনা (এডিট পেজ), পাইকারি প্রাইস লেভেল, VAT কনফিগ, বারকোড, সার্ভার-সাইড সার্চ, non-stock আইটেম, স্যাম্পল পেজ ও মৃত কোড সরানো।
**পূর্বশর্ত:** P03। **সিদ্ধান্ত:** D2, D6, D20। **পড়ুন:** `04` ফিচার ৩, ১১, ১২; `03` §৫।

## টাস্ক

1. **মাইগ্রেশন** `03` §৫: products (`isService`, `vatRate`, `vatMode`, `genericName`), `price_levels`, `product_prices` (level × minQty), `customer_types.priceLevelId`। বিদ্যমান `sellingPrice` → Retail সারি, `wholesalePrice` → Wholesale সারি (ব্যাকফিল)।
2. **`modules/pricing/resolvePrice(product, variant, level, qty)`:** সবচেয়ে বড় `minQty ≤ qty` সারি; না পেলে Retail; ভ্যারিয়েন্ট দাম আগে; `minimumPrice`-এর নিচে নয়। ইউনিট টেস্ট টেবিল (১০+ কেস)।
3. **পণ্য ডিটেইল/এডিট পেজ** `/products/[id]` (H9): সাধারণ তথ্য, ইউনিট, ক্যাটাগরি/ব্র্যান্ড/জেনেরিক, VAT, লেভেল-দামের টেবিল (লেভেল × পরিমাণ ধাপ), reorder level, ট্র্যাকিং ফ্ল্যাগ, ছবি, বারকোড তালিকা, ভ্যারিয়েন্ট, বর্তমান স্টক (গুদাম অনুযায়ী), avg cost ও মার্জিন (D20 পারমিশন), স্টক লেজার ট্যাব। PATCH API পারমিশনসহ; দাম বদলের অডিট।
4. **প্রাইস লেভেল সেটিংস পেজ** ও কাস্টমার টাইপ → লেভেল।
5. **ভ্যারিয়েশন পেজ** `/products/variations` (H10): হেড/ভ্যালু ব্যবস্থাপনা, পণ্যে ভ্যারিয়েন্ট তৈরি — স্যাম্পল ডাটা নয়।
6. **বারকোড** (ফিচার ১১): একাধিক বারকোড, EAN-13 জেনারেটর (ইন্টার্নাল প্রিফিক্স), লেবেল প্রিন্ট (A4 + ৩৮×২৫mm, লেভেল-দাম বাছাই), কপি সংখ্যা, প্রিন্ট অডিট রিপোর্ট।
7. **সার্ভার সার্চ API** (N8): `/api/v1/search/products?q=&level=` (নাম, SKU, বারকোড, জেনেরিক; available qty ও লেভেল-দাম সহ; ২০টি); `/search/customers`। POS-এর ২০০-সীমা অপসারণ P06-এ এটা ব্যবহার করবে।
8. **Non-stock আইটেম:** `isService` পণ্য স্টক মুভমেন্ট ছাড়া বিক্রিযোগ্য (সার্ভিস চার্জ, পরিবহন সেবা)।
9. **CSV import/export** হালনাগাদ: নতুন কলাম (লেভেল দাম, VAT, জেনেরিক)। H6 বজায়।
10. **মৃত কোড** (L3, L4, LV-7): `[...slug]`, `ModuleScreen`, `lib/screens` স্যাম্পল, `lib/mock`, অব্যবহৃত কম্পোনেন্ট মুছে ফেলা। মেনু-রুট টেস্ট: মেনুর প্রতিটি লিংক 200 দেয় ও "sample" শব্দ নেই; যেসব মেনু রুট নেই (যেমন `/sms/recharge`, `/api-logs`) সেগুলো মেনু থেকে সরানো।

## টেস্ট

- দাম নির্বাচন: Retail/Wholesale/Dealer × পরিমাণ ধাপ × ভ্যারিয়েন্ট × minimumPrice
- ক্যাশিয়ার রোলে cost/মার্জিন ফিল্ড API রেসপন্সে নেই
- বারকোড unique (একই org-এ ডুপ্লিকেট 409)
- সার্চ: ১০০০ পণ্য সিড → ৫০১তম পণ্য নামে খুঁজে পাওয়া যায়
