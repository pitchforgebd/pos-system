# P13 — বাংলা UI, ৳ ও ব্যবহারযোগ্যতা

**লক্ষ্য:** পুরো অ্যাপ বাংলায় (ইংরেজি বিকল্প), ৳ ও ঢাকা সময়, বাংলা ফন্ট, মোবাইল ও ট্যাবলেটে ব্যবহারযোগ্য, পরিষ্কার লোডিং/এরর অবস্থা।
**পূর্বশর্ত:** P12। **সিদ্ধান্ত:** D19। **পড়ুন:** `frontend-design` নীতি (বিদ্যমান শেল ডিজাইন বজায় রেখে)।

## টাস্ক

1. **i18n ক্যাটালগ** (H11): `src/lib/i18n/messages/{bn,en}.ts`; টাইপ-সেফ কী (অনুপস্থিত কী = typecheck ব্যর্থ)। ক্রম: POS → ড্যাশবোর্ড → বিক্রি/অর্ডার → পণ্য/স্টক → কাস্টমার/Vendor → টাকা/খরচ → রিপোর্ট → সেটিংস। এরর বার্তা (envelope code → বাংলা) সহ।
2. **H12:** `<html lang>` কুকি থেকে।
3. **টাকা ও সংখ্যা** (U5, L6): `formatMoney(Decimal|string)` → `৳১২,৩৪,৫৬৭.০০` (লাখ-কোটি গ্রুপিং); অংক বাংলা/ইংরেজি সেটিং (D19)।
4. **তারিখ** (U6): প্রদর্শন `Asia/Dhaka`, বাংলা মাসের নাম ঐচ্ছিক।
5. **ফন্ট** (L14): `next/font` দিয়ে বাংলা ফন্ট (Hind Siliguri বা Noto Sans Bengali) সাবসেট।
6. **লোডিং ও এরর** (U1): ভারী রুটে `loading.tsx`, `error.tsx`, খালি অবস্থা।
7. **শেল** (U3): স্ট্যাটিক অংশ সার্ভার কম্পোনেন্ট।
8. **মোবাইল** (U2): সার্চ আইকন/ড্রয়ার, টেবিল কার্ড ভিউ, POS ট্যাবলেট লেআউট, টাচ সাইজ।
9. **কনট্রাস্ট** (U9): গ্রেডিয়েন্ট কার্ড WCAG AA।
10. **প্রিন্ট:** ইনভয়েস, রসিদ, রিপোর্ট বাংলায় সঠিক রেন্ডার (A4 ও ৮০mm)।

## টেস্ট

- ক্যাটালগে bn ও en কী সমান (টেস্ট)
- `formatMoney("1234567.5")` → `৳১২,৩৪,৫৬৭.৫০`
- মেনু-রুট টেস্ট বাংলা মোডে: কোনো পেজে ইংরেজি UI স্ট্রিং অবশিষ্ট নেই (তালিকাভুক্ত স্ক্রিন)
