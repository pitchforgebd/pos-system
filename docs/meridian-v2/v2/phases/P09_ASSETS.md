# P09 — কোম্পানির সম্পদ

**লক্ষ্য:** স্থায়ী সম্পদ রেজিস্টার, অবচয়, বিক্রি/বাতিল; "কোম্পানির মোট সম্পদ" এক জায়গায়।
**পূর্বশর্ত:** P08। **সিদ্ধান্ত:** D8। **পড়ুন:** `02` #36–#38; `03` §১০; `04` ফিচার ৫।

## টাস্ক

1. **মাইগ্রেশন** `03` §১০।
2. **সম্পদ রেজিস্টার:** কোড, নাম, ক্যাটাগরি (গাড়ি, ফার্নিচার, কম্পিউটার, গুদাম সরঞ্জাম, অন্যান্য), ক্রয় তারিখ, মূল্য, অবশিষ্ট মূল্য, আয়ু (মাস), অবস্থান/ব্রাঞ্চ, ছবি/নোট। ক্রয় পোস্ট #36 (নগদ/ব্যাংক বা Vendor বাকি)।
3. **বিদ্যমান সম্পদ এন্ট্রি:** opening হিসেবে (Dr FIXED_ASSET, Cr ACCUM_DEPR আগের অবচয়, Cr OPENING_EQUITY)।
4. **মাসিক অবচয়** (#37, D8): মাস বাছাই → প্রতিটি সক্রিয় সম্পদের straight-line হিসাব → প্রিভিউ → এক জার্নাল; একই মাস দুইবার নয় (`depreciation_runs` unique)। মাস শেষে ড্যাশবোর্ডে রিমাইন্ডার।
5. **বিক্রি/বাতিল** (#38): লাভ/ক্ষতি হিসাব।
6. **সম্পদ রিপোর্ট:** রেজিস্টার, মোট মূল্য, জমা অবচয়, বর্তমান মূল্য; ক্যাটাগরি অনুযায়ী।
7. **"মোট সম্পদ" কার্ড ও পেজ:** ক্যাশ + ব্যাংক + মোবাইল + কাস্টমার বাকি + কুরিয়ার পাওনা + Vendor অগ্রিম + স্টক মূল্য + স্থায়ী সম্পদ (নিট) — প্রতিটি লিংকসহ; এবং দায় (Vendor বাকি, কাস্টমার অগ্রিম, ঋণ, VAT) — নিট মূল্য।
