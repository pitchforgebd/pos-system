# P05 — ক্রয় v2

**লক্ষ্য:** পূর্ণ ক্রয় প্রক্রিয়া — খসড়া/অর্ডার/গ্রহণ, ডিসকাউন্ট, VAT, পরিবহন খরচ (landed cost), বিলের পেমেন্ট স্ট্যাটাস, Vendor বাকি ও অগ্রিম, Vendor পেমেন্ট চার্জসহ।
**পূর্বশর্ত:** P04। **সিদ্ধান্ত:** D2, D3। **পড়ুন:** `02` #11–#16; `03` §৬; `04` ফিচার ৬, ৭, ১২।

## টাস্ক

1. **মাইগ্রেশন** `03` §৬ (purchases status/মোট/পরিবহন, items landed cost/লট, `vendor_payments`, ইন্ডেক্স D4)।
2. **গণনা** (`02` §৩): লাইন ডিসকাউন্ট, হেডার ডিসকাউন্ট (allocate), VAT (D2: খরচে যোগ বা Input VAT), পরিবহন ও অন্যান্য খরচ মূল্য-অনুপাতে লাইনে ভাগ → `landedUnitCost` (৪ দশমিক)। ইউনিট টেস্ট: যোগফল হুবহু বিলের মোট।
3. **স্ট্যাটাস:** DRAFT (কিছু পোস্ট নয়) → ORDERED (Vendor-কে পাঠানো; প্রিন্ট PO) → RECEIVED (`post()`: স্টক IN landed cost-এ + জার্নাল #11, #12) ; CANCELLED শুধু RECEIVED-এর আগে। আংশিক গ্রহণ: এই ফেজে না (মালিককে জিজ্ঞেস করে পরে)।
4. **পরিবহন** (ফিচার ৭): ক্রয়ে পরিবহনকারী, গাড়ি নং, ভাড়া, লেবার; ভাড়া কাকে দেওয়া (নগদ/পরিবহনকারীর বাকি)।
5. **Vendor পেমেন্ট** (#13): মেথড অ্যাকাউন্ট (ক্যাশ/ব্যাংক/মোবাইল), চার্জ, নির্দিষ্ট বিলে বা FIFO allocation; রসিদ প্রিন্ট।
6. **Vendor অগ্রিম** (#14, #15) ও বিলে সমন্বয়।
7. **Supplier return** UI P03-এর ইঞ্জিনে; ফেরতের টাকা AP কমায় বা নগদ/ব্যাংকে ফেরত।
8. **Vendor প্রোফাইল:** তথ্য, বাকি, অগ্রিম, বিল তালিকা (পেমেন্ট স্ট্যাটাস), লেজার, পেমেন্ট ইতিহাস।
9. **রিঅর্ডার → ক্রয় খসড়া** (P03-এর তালিকা থেকে এক ক্লিকে DRAFT)।
10. idempotency সব পোস্টে; ফর্ম `useSubmit`।

## টেস্ট

- ৩ লাইন + হেডার ডিসকাউন্ট + পরিবহন → landed cost যোগফল = বিল মোট + পরিবহন; avg cost আপডেট সঠিক
- RECEIVED দুইবার (একই key) → একবার স্টক
- আংশিক পেমেন্ট → PARTIAL; বাকি পরিশোধ → PAID; বেশি পেমেন্ট → বাতিল (অগ্রিম হিসেবে নিতে বলে)
- bKash পেমেন্ট চার্জসহ → 6610 লাইন, AP সঠিক
- প্রতিটির পর `assertBooksReconcile`
