# P07 — পরিবহন ও Condition (COD)

**লক্ষ্য:** বিক্রির ডেলিভারি তথ্য (নিজস্ব গাড়ি/কুরিয়ার), কুরিয়ারের COD (Condition) টাকা, Condition চার্জ, ডেলিভারি চার্জ, কুরিয়ার সেটেলমেন্ট, ফেরত পার্সেল — সব হিসাবসহ।
**পূর্বশর্ত:** P06। **সিদ্ধান্ত:** D4, D13। **পড়ুন:** `02` #24–#29; `03` §৮; `04` ফিচার ৭, ৯, ১৪; `05` রিপোর্ট ৪।

## টাস্ক

1. **মাইগ্রেশন** `03` §৮: `shipments`, `shipment_events`, `courier_settlements` + items, couriers-এ ডিফল্ট চার্জ। কুরিয়ার = partyType COURIER।
2. **কুরিয়ার সেটআপ:** তালিকা (D13 ডিফল্ট সিড), ডিফল্ট Condition %, ডিফল্ট ডেলিভারি চার্জ (ঢাকা/বাইরে)।
3. **শিপমেন্ট তৈরি:** অর্ডার DISPATCHED-এর সময় ডেলিভারি পদ্ধতি অনুযায়ী:
   - PICKUP: শিপমেন্ট নেই
   - OWN_VEHICLE: গাড়ি নং, চালক, ভাড়া (#29)
   - COURIER: কুরিয়ার, ট্র্যাকিং, COD টাকা (= বাকি অংশ), ডেলিভারি চার্জ, Condition চার্জ → #24, #25, #26 একই tx-এ
4. **স্ট্যাটাস ও ইভেন্ট:** CREATED → PICKED → IN_TRANSIT → DELIVERED / RETURNED / LOST; টাইমলাইন; অর্ডার স্ট্যাটাস সিঙ্ক (DELIVERED → অর্ডার DELIVERED)।
5. **ফেরত পার্সেল** (#28): RETURNED → COURIER_AR থেকে AR-এ ফেরত → পূর্ণ সেল রিটার্ন (স্টক ফেরত); ফেরত চার্জ থাকলে 6700।
6. **আংশিক ডেলিভারি:** মালিককে জিজ্ঞেস করো — এই ফেজে শুধু পূর্ণ ডেলিভারি বা পূর্ণ ফেরত হলে তাই লেখো।
7. **সেটেলমেন্ট** (#27): কুরিয়ার বাছাই → DELIVERED অথচ অসেটেলড শিপমেন্ট তালিকা → টিক → মোট COD, চার্জ, নিট → প্রাপ্ত অ্যাকাউন্ট; পার্থক্য থাকলে কারণসহ সমন্বয় (মালিকের অনুমোদন)। CSV ইমপোর্ট (কুরিয়ারের পেমেন্ট শিট) ঐচ্ছিক।
8. **Condition ড্যাশবোর্ড:** কুরিয়ার অনুযায়ী পাওনা, ৭ দিনের বেশি অসেটেলড সতর্কতা।
9. **API ইন্টিগ্রেশন:** এই ফেজে নয় (D13); শুধু `CourierProvider` ইন্টারফেস ও manual বাস্তবায়ন।
